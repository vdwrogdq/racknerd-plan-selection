## 1GB 还是 2GB：按站点类型对号

**纯博客、静态站、作品集、练手环境，1GB 就够。** $21.99 一年，20GB SSD 放一个 WordPress 站绰绰有余。有长期用户自述，1GB 方案跑 WordPress 加几个常用插件，月流量用不到 200GB，离 3TB 的上限差着十几倍。学习用途装 Docker、跑几个容器、反复重装系统试各种面板，这台机器也扛得住。

**WordPress 装了一堆插件，或者做企业官网，从 2GB 起。** 缓存插件、SEO 插件、统计代码、联系表单叠上去，1GB 内存给 PHP 和 MySQL 留的余量就很薄，峰值时段容易 502。2GB 那档给 2 核、35GB SSD、5TB 流量，多出来的 $14 换来的是后台点开不卡。

**8GB 那档多数个人站长用不上。** 7 核、150GB SSD、20TB 月流量，是给多站点聚合或者跑轻量 API 服务准备的。博客站买它，钱花在了永远用不到的核数上。

## 从付款到 WordPress 上线：七步

1. **下单**。在五档里选一档，结算页选机房。支付方式支持支付宝、PayPal、信用卡、加密货币等，具体以结算页列出的为准。
2. **等开通邮件**。机器一般 5–15 分钟开好，邮件标题类似 "KVM VPS Login Information"，里面有 IP、root 密码和 SolusVM 面板地址。KVM 套餐是自动开通，不用等人工审核。
3. **SSH 登录**。终端里执行 `ssh root@你的IP`，粘贴初始密码。进去第一件事是改密码、加 SSH 密钥，裸密码登录风险高。
4. **确认系统镜像**。支持 CentOS、AlmaLinux、RockyLinux、Debian、Ubuntu，也能开工单挂自定义 ISO。新手选 Debian 12 或 Ubuntu 22.04 LTS，社区资料多，遇到问题好搜。
5. **装宝塔面板**。一行命令：`curl -sSO https://download.bt.cn/install/install_panel.sh && bash install_panel.sh`，跑完用浏览器登录面板，LNMP 环境在图形界面里配。
6. **部署 WordPress**。宝塔的"软件商店 → 一键部署 → WordPress"，填域名和数据库信息。WordPress 要求 PHP 7.3+、MySQL 5.6+，宝塔默认装的版本都满足。然后去域名服务商把 A 记录指向这台机器的 IP。
7. **开防火墙**。默认状态下系统防火墙不一定启用，用 UFW 配一遍：`ufw default deny incoming`、`ufw default allow outgoing`、`ufw allow ssh`、`ufw allow 80/tcp`、`ufw allow 443/tcp`，最后 `ufw enable`，用 `ufw status` 查看规则是否生效。80 和 443 没放行，网站会打不开。

第一次走完这套流程大概一到两小时，熟悉之后半小时内能搞定。真正卡人的通常不是命令，是选机房和挑配置。

## 哪些情况不适合用 RackNerd 建站

**需要极低延迟的场景。** 游戏服务器、实时音视频、对 RTT 敏感的应用，香港机房 30–50ms 的物理延迟更合适，代价是同配置月付 $5–8，一年下来是 RackNerd 的三到五倍。

**完全不想碰命令行。** 宝塔能把建站操作搬到浏览器里，但第一次装面板仍然要 SSH 执行一条命令，这一步绕不过去。

**需要 cPanel 分销主机。** RackNerd 有独立的分销主机产品线，机房分布和 KVM VPS 不同，跟本文这套建站方案不是一回事。

**需要独服性能。** 独立服务器是另一条产品线，起步价 $139/月，跟年付二十几美元的 VPS 不是一个量级的需求。

## 常见问题

**服务器在境外，真的不用备案？** 机房全部在中国大陆境外，域名解析到这些 IP 上直接能访问，没有 ICP 备案的前置审批。这是免备案建站最直接的实现方式。

**1GB 内存跑得动 WordPress 吗？** 跑得动，前提是别装太多插件、不上 WooCommerce。1GB 是底线不是舒适线，插件一多就该考虑 2GB。

**3TB 月流量够用吗？** 个人博客级别远远够。一个日均几百 PV 的 WordPress 站，月流量通常几十 GB 量级，离 3TB 差得很远。

**能装 Docker 或者其他面板吗？** 给的是 root 权限和 KVM 虚拟化，Docker、1Panel、aaPanel 都能装，SolusVM 里随时重装系统换发行版。

**续费会不会第二年涨价？** 年付特价续费保持原价，这点在官方促销说明和多位长期用户的说法里是一致的，也是这类低价 VPS 里比较少见的做法。下单时确认一下页面上的续费说明即可。

**支持 IPv6 吗？** 洛杉矶和法国机房可以开工单申请最多 100 个免费 IPv6 地址，其他机房陆续支持中。
